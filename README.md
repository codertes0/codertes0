# Lorenzo Falavina Grigoletto

Desenvolvo sites, automações e produtos com IA: de sites institucionais para clínicas a agentes que atendem clientes no WhatsApp e ferramentas que rodam modelos de linguagem e de voz.

## Projetos

| Projeto | O que é | Stack |
|---|---|---|
| [**Estúdio de motion**](https://github.com/codertes0/estudio-de-motion) | Cole o link de um site e veja efeitos de movimento funcionando nas seções dele. Depois, exporte o pacote ou um prompt para o Claude Code instalar. | Node.js · Chrome headless (Playwright) · anime.js · Vercel |
| [**Atendimento no WhatsApp com IA**](https://github.com/codertes0/chatbot-whatsapp-n8n) | Agente de vendas que mostra produtos, busca peças pela cor, fecha pedido, salva leads e passa a conversa para um humano. | n8n · Evolution API · Groq (Llama 3.3) · Redis · Google Sheets |
| [**Triagem de veículos**](https://github.com/codertes0/santa-emilia-triagem) · [ver no ar](https://santa-emilia-triagem.vercel.app) | Cinco perguntas e uma indicação dos carros mais compatíveis, com link para o estoque. | HTML · CSS · JavaScript |
| [**Ditado por voz local**](https://github.com/codertes0/whisper-ditado-local) | Segure uma tecla, fale e o texto aparece em qualquer app. Roda 100% no computador. | Python · faster-whisper · CUDA |
| **Quiz diário de atualidades** · [ver no ar](https://codertes.vercel.app) | Quiz gerado por IA a partir das notícias do dia. O código é privado. | Python · FastAPI · Claude API · Upstash Redis · Vercel |

## Sites para clientes

O código é privado; os sites estão no ar.

- [**Doctor Kids**](https://doctorkids-site.vercel.app): clínica materno-infantil em Valinhos/SP, com páginas por especialidade e por profissional.
- [**Medvacinas**](https://medvacinas.com.br): centro de imunizações em Valinhos/SP.

## Tecnologias

- **Linguagens:** Python · JavaScript · HTML · CSS
- **Back-end e dados:** FastAPI · Node.js · Redis · Supabase · Google Sheets API
- **IA:** Claude API · Groq / Llama · Whisper · n8n (agentes e automação)
- **Front-end e motion:** GSAP · anime.js · Lenis
- **Infra e ferramentas:** Vercel · GitHub Actions · Playwright · Git
